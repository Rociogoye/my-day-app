# Acceso a My Day y descarga de versiones

## Cómo descargar la aplicación

1. Abre uno de los enlaces de descarga de esta sección.
2. En Google Drive, pulsa el icono de descarga.
3. Guarda el archivo HTML en una carpeta de tu ordenador.
4. Si el navegador descarga un archivo comprimido, descomprímelo antes de continuar.
5. Comprueba que el archivo se llama `index.html` o conserva el nombre de la versión para distinguirlo.

## Cómo abrirla haciendo doble clic

1. Abre Finder o el explorador de archivos.
2. Ve a la carpeta donde guardaste el archivo.
3. Haz doble clic sobre el archivo `.html`.
4. Se abrirá en el navegador predeterminado.
5. La aplicación funciona localmente y guarda los datos en el navegador mediante `localStorage`.

Al abrirla de esta forma, la dirección tendrá un formato parecido a:

```text
file:///Users/tu-nombre/Downloads/index.html
```

## Cómo abrirla con Visual Studio Code y Live Server

1. Instala Visual Studio Code si todavía no lo tienes.
2. Abre Visual Studio Code.
3. Selecciona **File > Open Folder**.
4. Elige la carpeta donde guardaste `index.html`.
5. En el panel de archivos, haz clic derecho sobre `index.html`.
6. Selecciona **Open with Live Server**.
7. Se abrirá una pestaña del navegador con una dirección similar a:

```text
http://127.0.0.1:5500/index.html
```

También puede aparecer como `http://localhost:5500/index.html`. El número de puerto puede variar. Debes utilizar la dirección que muestre Live Server.

## Diferencia entre las versiones

Las versiones 1, 2 y 3 muestran el proceso de evolución de la aplicación. La versión final contiene la integración más completa de tareas, hábitos, calendario, temporizador, estadísticas, navegación y diseño visual.

## Importante sobre los datos

Los datos se guardan en el navegador y en el dispositivo desde el que se utiliza la aplicación. No se sincronizan automáticamente entre ordenadores o navegadores diferentes. Para conservarlos, utiliza la función de exportación JSON incluida en la aplicación.
